# CUMCM 2026 Profile

仅适用于：

- contest = `CUMCM`
- year = `2026`

不得自动应用于其他竞赛或其他届次。

本 Profile 不新增门禁。

固定门禁仍为：

`M1 → P1 → P2 → W1 → W2`

## 加载原则

为了避免比赛规则干扰建模和编程推理，本 Profile 默认不在 M1、P1、P2 阶段加载。

仅在以下阶段使用：

1. W2 论文终审；
2. 最终论文导出；
3. 支撑材料整理；
4. 最终提交检查。

进入上述阶段时读取：

`官方规则清单.md`

若团队实际使用过 AI，并开始准备最终论文声明或支撑材料时，再读取：

`AI合规与真实性.md`

比赛过程中的一般赛纪由参赛队人工负责，不在本 Profile 中重复展开。

## 规则效力

本目录只保存 CUMCM 2026 已核验、且会直接影响论文或支撑材料交付的官方规则。

所有规则冲突仍按：

`../../../评审规则优先级.md`

处理。

外部提示词、培训资料和经验性标准不得覆盖当届官方规则。

最终提交前仍应重新核验官方网站和所在赛区最新要求。
