# 评审规则优先级

本文件定义数学建模过程中不同来源规则、标准、经验和判断依据的优先级。

目的不是增加新的比赛规则，而是防止：

- 往届经验冒充当届官方要求；
- 网络文章或提示词中的经验阈值冒充硬性标准；
- 未经核验的说法直接触发 FAIL；
- 不同参考资料发生冲突时由 Agent 自行猜测；
- 为追求所谓“获奖模板”而违反当届官方要求。

本文件适用于：

- 建模方案检查；
- 编程与结果检查；
- 论文评审；
- 格式审查；
- 合规检查；
- 导入外部提示词、经验清单和优秀论文规律时的规则归类。

---

## 一、四级规则来源

所有会影响模型选择、结果判断、论文修改、质量门禁或合规结论的规则，
原则上归入以下四级之一。

### A — VERIFIED_OFFICIAL

已经核验且适用于当前目标竞赛、当前届次的官方材料。

典型来源包括：

- 当届官方竞赛规则；
- 当届官方论文格式规范；
- 当届官方模板；
- 当届官方通知；
- 当届官方 AI 使用规则；
- 官方网站对当前届次明确发布的补充说明；
- 具有明确适用范围的赛区官方要求。

A 级规则可以形成：

- 硬性约束；
- 合规要求；
- 提交要求；
- P0 问题；
- 门禁 FAIL 的直接依据。

使用 A 级规则时必须能够说明：

- 来源；
- 适用竞赛；
- 适用届次；
- 适用范围；
- 如有必要，具体条款或页面位置。

不得仅因为某项规则“历年如此”就归入 A 级。

---

### B — VERIFIED_EXTERNAL

已经核验，但不属于目标竞赛官方规则的外部事实、学术依据或领域规范。

典型来源包括：

- 可追溯的学术论文；
- 教材或专著中的理论；
- 权威机构公开数据；
- 领域技术标准；
- 数据集官方说明；
- 软件、算法或统计方法的权威文档；
- 已经实际核验的题目附件事实；
- 经实际计算得到的数据事实。

B 级规则主要用于：

- 模型选择依据；
- 参数来源；
- 假设依据；
- 数据处理依据；
- 算法适用性；
- 结果合理性；
- 误差与边界判断；
- 论文论证和引用。

B 级规则不能冒充比赛官方要求。

例如：

某统计方法通常要求满足特定假设，
可以据此判断模型是否适用；

但不能因此宣称：

“国赛官方规定必须使用该统计方法”。

---

### C — HEURISTIC

经验性质量标准、评审经验、优秀论文规律、写作建议或启发式阈值。

典型来源包括：

- 数学建模评审经验；
- 历届优秀论文中常见的结构规律；
- 教师或参赛经验总结；
- 外部提示词；
- AI 提示词中的质量检查维度；
- Skill 内部设置的质量目标；
- 非官方的篇幅、图表数量、假设数量或摘要长度建议；
- 非官方的评分权重；
- 非官方的所谓获奖概率、获奖等级预测方法。

C 级规则可以用于：

- 提升论文质量；
- 发现潜在薄弱点；
- 提醒增加验证；
- 改善表达；
- 比较多个可行方案；
- 排定优化优先级。

C 级规则不得：

- 冒充当届官方规则；
- 单独制造 P0；
- 在与 A 级规则冲突时覆盖 A 级规则；
- 仅因为未达到某个经验数字就直接判定比赛不合格；
- 被描述成“官方规定”“官方评分标准”或“硬性要求”。

当 C 级规则包含数字阈值时，应优先表述为：

- 建议；
- 质量目标；
- 经验范围；
- 默认目标；
- 启发式检查项。

除非后来取得 A 级来源证明，否则不得升级为官方硬约束。

---

### D — UNVERIFIED

尚未核验来源、适用性或真实性的说法。

典型情况包括：

- 不知道出处的网络说法；
- AI 自行生成但尚未验证的事实；
- 无法确认是否适用于当前届次的历史规则；
- 不知道原始出处的评分权重；
- 未核验的所谓评委偏好；
- 未确认的数据、参数或文献；
- 外部提示词中直接声称“官方要求”但没有官方来源的内容。

D 级内容只能作为：

- 待核验线索；
- 搜索方向；
- 风险提示。

D 级内容不得：

- 单独触发 FAIL；
- 单独形成 P0；
- 直接写成论文事实；
- 作为关键参数唯一依据；
- 作为删除或替换模型的唯一理由；
- 被转述为官方要求。

需要依赖该内容作出重要决定时，应先核验并升级到 A、B 或 C。

---

## 二、冲突处理顺序

不同来源发生冲突时，按以下顺序处理：

`A > B > C > D`

但该顺序只表示规则权威性，不表示任何 A 级内容都与任何 B 级内容直接竞争。

必须先判断它们是否在回答同一个问题。

例如：

- A 级决定论文页数上限；
- B 级决定某种算法的数学适用条件；

二者属于不同作用域，不构成冲突。

真正发生冲突时：

1. 先确认两个规则是否适用于相同竞赛、届次、文件和任务；
2. 优先执行适用范围更明确的 A 级规则；
3. A 级没有规定的问题，可使用 B 级事实和理论；
4. B 级仍不足时，可使用 C 级经验优化；
5. D 级只能保留为待核验事项。

---

## 三、官方规则具有届次和作用域

“官方”不是永久标签。

某项官方规则至少应考虑：

- 哪个竞赛；
- 哪个年份或届次；
- 哪个赛区；
- 哪种提交格式；
- 哪个阶段；
- 是否仍然有效。

往届官方规则在没有确认继续适用于当前届次之前，
不得直接作为当前届次的 A 级规则。

可以暂时归类为：

`D — UNVERIFIED`

完成核验后再升级。

---

## 四、导入外部提示词时的处理

任何外部提示词、检查表、经验清单或 AI 生成的评审规则，
都不得因为其标题包含以下词语而自动获得更高优先级：

- 官方；
- 标准版；
- 评委标准；
- 国赛标准；
- 获奖标准；
- 终极版；
- 权威；
- 满分；
- 国一；
- 国二。

导入时必须逐条判断其实际依据。

外部提示词中的内容通常分为三类：

### 可直接吸收的检查维度

例如：

- 模型是否真正回答子问题；
- 假设是否有依据；
- 参数是否可确定；
- 是否有验证；
- 数据与图表是否一致；
- 文献是否真实；
- 结论是否有证据支撑。

这类内容通常可作为 C 级质量检查维度。

若同时有 B 级理论或 A 级官方依据，则按相应级别执行。

### 可以吸收但必须降级为经验建议的数字

例如：

- 摘要建议多少字；
- 建议几条假设；
- 建议多少页；
- 建议多少张图；
- 某部分建议占多少比例；
- 某种模型建议至少几个；
- 某种奖项概率。

如果没有当前届次官方依据，
统一视为 C 级启发式建议，
不得包装成 A 级硬规则。

### 必须核验后才能采用的事实

例如：

- “官方明确规定……”
- “评委按某固定权重评分……”
- “某届必须……”
- “未达到某数量直接取消资格……”

没有可核验来源时统一为 D 级。

---

## 五、数字阈值规则

数字是最容易被错误硬编码的内容。

任何会产生以下结果的数字阈值：

- 自动 FAIL；
- P0；
- 判定违规；
- 判定没有获奖可能；
- 强制增加或删除模型；
- 强制修改论文结构；

必须先回答：

“这个数字来自哪里？”

如果来自当前适用的 A 级规则，可以作为硬约束。

如果来自 B 级理论，应按该理论的适用条件使用。

如果只是经验或质量目标，则属于 C 级。

如果来源不明，则属于 D 级。

不得因为数字看起来精确，
就默认其比定性判断更可靠。

---

## 六、奖项预测

任何奖项等级、国一概率、国二概率、获奖概率或百分制预测，
默认属于：

`C — HEURISTIC`

除非竞赛官方公开了可直接推导该结论的完整评分方法，
否则不得：

- 描述为官方评分；
- 描述为可靠概率；
- 用概率直接决定门禁 PASS/FAIL；
- 为提高所谓预测概率而违反模型合理性或官方规则。

允许使用更克制的内部评价，例如：

- `S`：竞争力强，主要风险已控制；
- `A`：整体完整，仍有明确可提升项；
- `B`：基本完整，但存在明显质量短板；
- `C`：存在影响竞争力的重大问题。

这种评价仍属于 C 级，
只能用于安排修改优先级。

---

## 七、FAIL 与问题等级

### P0

通常包括：

- 违反适用的 A 级硬规则；
- 核心数学或逻辑错误；
- 伪造数据、文献或实验；
- 关键结果无法由实际代码或证据支持；
- 其他会使核心结论失效的问题。

### P1

通常包括：

- 复现失败；
- 关键模型适用性没有得到支持；
- 重要约束遗漏；
- 主要结论与数据或代码不一致；
- 对最终质量有实质影响的严重问题。

### P2

通常包括：

- 非阻塞性的表达改进；
- 图表优化；
- 更好的解释方式；
- C 级经验标准下的质量提升建议。

不得因为单纯没有满足某个 C 级经验阈值，
就自动升级为 P0。

---

## 八、规则来源必须可追溯

当某项规则实际影响了重要决定时，
至少应能够回答：

- 规则是什么；
- 属于 A/B/C/D 哪一级；
- 来源在哪里；
- 为什么适用于当前任务；
- 是否与其他规则冲突；
- 最终如何处理。

无需为每个普通写作建议都创建复杂记录，
但涉及以下事项时应保留依据：

- 官方合规；
- 模型选择；
- 关键假设；
- 关键参数；
- 数据来源；
- 论文提交要求；
- 可能导致门禁 FAIL 的规则。

---

## 九、与门禁的关系

本文件不新增门禁。

固定门禁仍然只有：

`M1 → P1 → P2 → W1 → W2`

不同阶段使用本规则的方式如下：

### M1

重点区分：

- 官方或题目硬约束；
- 已验证的数学/领域依据；
- 模型选择经验；
- 未核验的所谓“高级模型更容易获奖”等说法。

### P1 / P2

重点区分：

- 实际输入和真实计算事实；
- 算法理论要求；
- 经验参数；
- 未核验参数来源。

### W1 / W2

重点区分：

- 当届官方论文要求；
- 引用和证据事实；
- 写作与评委经验；
- 外部提示词中的非官方评分规则。

任何门禁都不得因为 D 级规则单独返回 FAIL。

---

## 十、使用原则

实际执行时遵循：

1. 先确定当前问题属于官方合规、数学事实、领域事实还是质量优化；
2. 再确定规则来源等级；
3. 优先使用高等级且真正适用的依据；
4. 不把经验包装成事实；
5. 不把往届规则包装成当届规则；
6. 不把 AI 生成判断包装成外部证据；
7. 不为了满足经验模板而牺牲问题适配性；
8. 无法确认时明确标记“待核验”，不要猜。

本体系的目标是：

让官方规则决定“能不能这样做”，
让真实证据和理论决定“这样做对不对”，
让经验标准帮助判断“怎样做得更好”。
